# 🚀 Algorithm Study

> **목표: 문제 해결능력 향상**

## 📌 진행 방식

- 플랫폼: **프로그래머스, 정올**
- **평일(월~금) 매일 Lv.3 ~ Lv.4 문제 1개** 풀이
- **주말(토·일)은 진행하지 않습니다.**
- 언어: **Java**
- 문제 풀이 후 개인 브랜치에 **Push → Pull Request(PR) 생성**

---

## 📢 문제 공지

- 매일 진행할 문제는 **GitHub Issue**를 통해 공지합니다.
- Issue에는 문제 링크, 난이도, 마감 일정 등을 작성합니다.
- 해당 Issue를 확인한 후 문제를 풀이해주세요.

### Issue 예시

```text
# Week01 Day01

- 플랫폼: 프로그래머스
- 문제: 문제 이름
- 난이도: Lv.3
- 링크: 문제 링크

마감: YYYY-MM-DD 23:59
```
---

## 📅 진행 순서

1. 오늘의 문제 확인
2. 문제 풀이
3. 개인 브랜치에 Push
4. Pull Request 생성
5. `main` 브랜치에 Merge

---

## 📂 디렉토리 구조

```text
2026-09/
└── week01/
    └── day01/
        ├── 본인이름.java
        └── ...
```

---


## 🌱 Git Flow

1. 최신 `main` 브랜치를 Pull 합니다.
2. 개인 브랜치에서 문제를 풉니다.
3. Push 후 Pull Request를 생성합니다.
4. 서로 코드 리뷰를 진행합니다.
5. 리뷰 반영 후 `main` 브랜치에 Merge합니다.
